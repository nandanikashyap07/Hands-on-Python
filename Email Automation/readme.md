# ====================================================
# Python Email Sender – Gmail SMTP Automation
# ====================================================

A compact Python script that sends emails using Gmail’s SMTP service.  
No third-party libraries — just Python + SSL + Gmail App Password.

🔥 What This Script Can Do
- Send emails directly from your terminal
- Uses Gmail’s secure SSL SMTP server
- Customize sender, receiver, subject & message
- Fully compatible with Gmail App Passwords
- Perfect for beginners learning automation

🧰 Tools & Libraries Used
Python 3.x  
smtplib  
ssl  
email.message.EmailMessage  

📦 Project Requirements
1) Install Python  
   https://www.python.org/downloads/

2) Generate Gmail App Password  
   - Go to Google Account → Security  
   - Enable 2-Step Verification  
   - Open “App Passwords”  
   - Create a 16-digit password  
   - Use that password inside the script

▶ How to Run
python email_sender.py

📬 Result
The receiver will instantly get your email with the subject and message you defined.
