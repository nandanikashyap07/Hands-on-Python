# 🎮 XO Game Using Python & Pygame 

A simple and interactive **Tic-Tac-Toe (XO) game** built using **Python** and **Pygame**, styled with a soft lavender background. This project demonstrates game logic, grid handling, event detection, and GUI rendering using Pygame.

---

## 💜 Features

* Lavender-themed background
* Smooth and clean grid design
* Turn-based X and O gameplay
* Winner detection
* Draw detection
* Auto restart after each match
* Easy-to-understand and beginner-friendly code

---

## 🛠 Tech Stack

* **Python 3**
* **Pygame**

---

## ▶️ How to Run the Game

### 1. Install required library

```bash
pip install pygame
```

### 2. Run the game

```bash
python xo_game.py
```
