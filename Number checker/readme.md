🔢 Number Checker in Python

A simple and beginner-friendly Python program that checks whether a given number is positive, zero, or negative. This project is perfect for learners who want to understand basic input handling and conditional statements in Python.

📜 Features

Takes user input

Checks if the number is positive, zero, or negative

Uses basic if-elif-else logic

Easy to understand and modify


▶️ How to Run

Save the code as check_number.py

Open your terminal or command prompt

Run the script:

python check_number.py


Enter any number to test the output

Python beginners

Students learning conditional statements

Small academic assignments

Quick logical practice programs
