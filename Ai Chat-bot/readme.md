
# 🤖 Gemini ChatBot - Streamlit App

This is an **interactive chatbot web app** built with **Python**, **Streamlit**, and **Google Gemini API**. The bot uses the **Gemini 2.5 Flash** model to generate AI-powered responses to user queries.

---

## 🔹 Features
- Ask any question and get instant AI-generated responses.
- Clean, user-friendly **Streamlit interface**.
- Easy configuration with your Gemini API key.
- No infinite loops — simply click **Generate Response**.
- Perfect for experimenting with generative AI in web apps.

---

## 💻 Installation

1. **Clone the repository:**
```bash
git clone https://github.com/yourusername/gemini-chatbot.git
cd gemini-chatbot
````

2. **Install dependencies:**

```bash
pip install streamlit google-generativeai
```

3. **Set your Gemini API key** in `app.py`:

```python
key = "ENTER YOUR KEY HERE"
```

4. **Run the Streamlit app:**

```bash
streamlit run app.py
```

---

## 📌 Usage

1. Enter your question in the input box.
2. Click **Generate Response**.
3. The bot will display a generated answer instantly.

---
