# 🌐 Personal Portfolio Website

### Built with **Python Flask, HTML, and CSS**

---

## 📌 Overview

This project is a **personal portfolio website** created using **Flask**, showcasing my skills, education, and projects as a B.Tech student specializing in **Artificial Intelligence & Machine Learning**.
The website is simple, responsive, and easy to deploy.

---

## 🚀 Features

* 🏠 **Home Section** – Introduction with name & role
* 👩‍💻 **About Section** – Skills and background
* 📁 **Projects Section** – Placeholder for future work
* ✉️ **Contact Section** – Email, LinkedIn & GitHub
* 🎨 **Clean UI** built with custom CSS
* ⚡ **Fast & Lightweight** Flask backend
* 📱 **Responsive Design**

---

## 🛠️ Technologies Used

* **Python**
* **Flask Framework**
* **HTML5**
* **CSS3**
* **VS Code**


## ▶️ How to Run the Project Locally

1. Clone the repository

   ```bash
   git clone <your-repo-link>
   ```
2. Navigate into the folder

   ```bash
   cd folder-name
   ```
3. Install Flask

   ```bash
   pip install flask
   ```
4. Run the app

   ```bash
   python app.py
   ```
5. Open in your browser:

   ```
   http://127.0.0.1:5000/
   ```
