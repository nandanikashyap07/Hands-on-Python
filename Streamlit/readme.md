# 🎓 Smart Attendance & Performance Dashboard

A fully interactive Streamlit-based dashboard that visualizes **student attendance**, **performance trends**, and **behavioral insights** using dynamic charts and analytics. This project demonstrates the power of combining **Python**, **Pandas**, **NumPy**, and **Plotly** to create a data-driven educational monitoring system.

---

## 🚀 Features

### 📌 **1. Smart Filters**

* Student selection
* Date range picker
* Attendance filter (Present/Absent)

### 📌 **2. Key Metrics**

* Attendance rate
* Average performance score
* Best score
* Lowest score

### 📌 **3. Visual Insights**

* 🟠 **Attendance Distribution (Donut Pie Chart)**
* 📈 **Performance Progress Over Time (Line Chart)**
* 🔥 **Monthly Performance Heatmap (Bar Graph)**
* 📆 **Weekly Attendance Trend (Line Chart)**

### 📌 **4. Detailed Logs**

* Complete daily student activity table
* Attendance and performance combined insights

## ▶️ How to Run

### **1. Clone the Repository**

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### **2. Install Dependencies**

```bash
pip install -r requirements.txt
```

### **3. Run the Streamlit App**

```bash
streamlit run app.py
```
