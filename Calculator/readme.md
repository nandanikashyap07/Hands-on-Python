# 🧮 Python CLI Calculator

A simple and interactive command-line calculator built using Python.
It supports basic arithmetic operations such as addition, subtraction, multiplication, division, and modulus, along with proper input validation and error handling.

---

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🟰 Modulus
* 🔁 Runs continuously until the user exits
* ⚠️ Handles invalid choices and non-numeric inputs gracefully

---

## 📌 How It Works

The calculator displays a menu of operations in a loop.
Users choose an operation, enter two numbers, and get the result instantly.
Invalid inputs are caught using `try-except`, ensuring the program doesn’t crash.

---

## 🎯 How to Run

1. Install Python (if not already installed)
2. Download or clone this repository
3. Run the program:

```bash
python calculator.py
```
