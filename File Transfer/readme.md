# 📂 File Transfer Script in Python

This project provides a simple and effective Python script to transfer files from one location to another. It uses the built-in shutil module and includes error handling to ensure smooth and safe file copying.

🚀 Features

Copy files from one directory to another

User-friendly input prompts

Built-in error handling for:

File not found

Permission denied

Unexpected errors

🧾 How It Works

The script asks the user for:

Source file path

Destination path

Then it attempts to copy the file using shutil.copy(). If anything goes wrong, it prints a clear error message.

📦 Requirements

Python 3.x

No external libraries needed

▶️ How to Run

Save the script as file_transfer.py

Open a terminal or command prompt

Run:

python file_transfer.py
