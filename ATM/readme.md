# **ATM System in Python**

This project is a simple and interactive Python-based ATM system that simulates basic banking operations. It includes secure PIN verification, deposit and withdrawal functionalities, input validation, and an automatic lockout after three invalid attempts.

---

## 🚀 **Features**

* 🔐 **PIN Verification** with numeric validation
* 💸 **Deposit & Withdrawal** operations
* ⚠️ **Three-attempt lockout** for incorrect PIN
* ✔️ Safe handling of user inputs
* 🧮 Real-time balance updates
* 📝 Clear prompts and user-friendly flow

---

## 📌 **How It Works**

1. User enters a PIN
2. System checks validity
3. On correct PIN → operations menu
4. User selects deposit or withdrawal
5. Balance updates accordingly
6. On three wrong PINs → ATM access blocked

---

The program uses:

* Basic arithmetic
