# 🎬 Movie Permission Checker – Python Project

A beginner-friendly Python program that determines whether a user can watch a movie based on **age** and **ticket availability**. This project demonstrates input handling, boolean logic, and conditional statements in a simple and interactive way.

---

## 🚀 Features

* Accepts user age as input
* Checks ticket availability
* Determines if the user can:

  * Watch the movie freely (18+)
  * Watch only with parents (≤15)
  * Not allowed (16–18 without meeting conditions)
* Clear and user-friendly output messages

---

## 💡 How It Works

1. User enters **age**
2. User enters **1 if they have a ticket** or **0 if not**
3. Program evaluates conditions and prints appropriate messages:

   * Adult access
   * Show ID
   * Ticket validation
   * Parental guidance
   * Restrictions

---



## 🎯 Purpose of This Project

This project is ideal for:

* Python beginners
* Learning **if-else conditions**
* Practicing user input
* Understanding boolean conversions

---

## 📂 How to Run

1. Save the code as `movie_checker.py`
2. Run in terminal or any Python IDE:

```bash
python movie_checker.py
```
