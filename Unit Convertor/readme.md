# 🧮 Python Unit Converter

A simple and interactive Python Unit Converter that helps users convert Length, Weight, Temperature, and Time units easily.
This beginner-friendly project is designed using basic Python concepts like functions, loops, and conditional statements.

🚀 Features

🔹 Length Conversion (m ↔ km, cm ↔ m)

🔹 Weight Conversion (g ↔ kg, lb ↔ kg)

🔹 Temperature Conversion (C ↔ F ↔ K)

🔹 Time Conversion (sec ↔ min ↔ hr)

🔹 Menu-driven user interface

🔹 Clean and readable code

🛠️ How to Run

Install Python 3.x on your system.

Download the project files.

Open terminal or CMD in the project folder.

Run the script:

python unit_converter.py

📘 Usage

Choose a category: Length, Weight, Temperature, Time.

Select the conversion type from the menu.

Enter the value.

Get the converted result instantly.
